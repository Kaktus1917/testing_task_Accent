файл подключения к серверу находится по пути исполняемого файла в bin, создавать его не надо, при первом запуске он создастся автоматически

-Мнгновенная фильтрация работает только при поиске по имени, доп.параметры применяются после их выбора и нажатия кнопки "Применить"

-Кнопка "настройки" открывает поля ввода для подключения к бд через юзера и пароль

-Кнопка "Построить график" открывает окно с параметрами двух графиков. Одновременно построить можно один график

хранимые процедуруы начинаются на cp_

Для вывода данных используется представление 

-Для сохранения и хранения данных подключения создан класс saveSystem

-Для работы с базой данных создан класс ManagerSQL
